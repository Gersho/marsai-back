### Endpoints
| Méthode | Route | Auth | Description |
|---------|-------|------|-------------|
| GET | `/events` | Non | Liste (filtre ?lang=FR/EN) |
| GET | `/events/:slug` | Non | Par slug |
| GET | `/events/:id/remaining-seats` | Non | Places restantes |
| POST | `/events` | Admin | Créer |
| PUT | `/events/:id` | Admin | Modifier |
| DELETE | `/events/:id` | Admin | Supprimer |

### Points forts identifiés
1. Génération automatique des slugs uniques
2. Gestion bilingue FR/EN
3. Logique "événements liés" (même date + lieu = capacité partagée)
4. Intégration bookings avec emails et JWT unsubscribe

### Points d'amélioration potentiels
1. Status incohérent entre validation Zod et DB ENUM
2. Pas de pagination sur findAll
3. Pas de soft delete
4. Manque de tests
5. Gestion des erreurs basique
